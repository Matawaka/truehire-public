# Граница происхождения TRUEHIRE

## Независимый программный объект

`TRUEHIRE / Честный найм` — новый независимый программный объект.

- Авторская линия: `КУЗНЕЦОВ ДМИТРИЙ ОЛЕГОВИЧ / MATAWAKA`;
- предыдущий параллельный проект: `Маркетолог Пессимист`, публичный программный объект `Matawaka/marketcloser-public`;
- обязательная протокольная основа: `Matawaka/uu-aap`;
- контрольная версия основной ветви UU-AAP, наблюдавшаяся при начале проекта: `d8500cdcbf9355cce71ce52beaea01c70e1a1c54`.

## Границы

`SAME_AUTHORSHIP_LINE != SAME_SOFTWARE_OBJECT`

`USE_OF_UU_AAP != MODIFICATION_OF_UU_AAP`

`TRUEHIRE_DEVELOPMENT != UU_AAP_SUCCESSOR_RELEASE`

`MARKETING_PESSIMIST != TRUEHIRE_MODULE`

Предыдущий проект был просмотрен только для чтения на версии `ac83932317cbfd56b7875c27d15d0cd1cac49fa6`, чтобы понять публичную авторскую зрительную линию. Ни один файл не был скопирован как часть TRUEHIRE; исходный проект не изменялся.
