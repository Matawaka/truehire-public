# Русский понятийный строй TRUEHIRE

Названия TRUEHIRE, UU-AAP и MATAWAKA не переводятся. Внутренние программные ключи могут оставаться латинскими, но не должны показываться человеку без русского названия.

## Основная цепочка

Состояние и опорные свидетельства → Возможность → Намерение → Полномочия и ответственность → Согласование сторон → Рубеж допуска → Действие → Результат → Последующее состояние.

## Обязательные различия

- свидетельство ещё не является доказательством;
- намерение ещё не является согласием;
- согласие ещё не является договором;
- полномочия не равны доступу к учётной записи;
- предположение ИИ не является знанием о человеке;
- сопоставление не создаёт обязанности;
- внутренняя возможность не разрешает действие вовне.

- Successor State → последующее состояние;
- Personal Need Deck → личная картотека потребностей;
- Personal Vault → личное защищённое хранилище;
- Selective Disclosure → выборочное раскрытие;
- Matching → сопоставление;
- Ranking → упорядочивание;

- Business People Plan → план потребности бизнеса в людях;
- Safe Workload → безопасная нагрузка;
